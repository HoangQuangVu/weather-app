# 🌤️ Weather App

A responsive weather application built with ReactJS that fetches real-time weather data using the OpenWeatherMap API.

## 🚀 Features
- Search weather by city name
- Display real-time temperature, humidity, and weather conditions
- Dynamic UI updates based on API response
- Responsive design for multiple screen sizes

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- ReactJS (useState, useEffect)
- OpenWeatherMap API

## 🔌 API Integration
- Fetch data from external API using `fetch`
- Handle asynchronous data and error cases
- Parse and display JSON data on UI

## 🧪 Testing
- Manual testing for API responses and UI rendering
- Checked edge cases (invalid city, empty input)
